# Banking System (Java)

Java source for the banking system. See the [repository README](../README.md) for the
full documentation, account rules and how to run the program.

## Quick start

```bash
javac -d bin src/BankingSystemMain.java src/banking/*.java
java -cp bin BankingSystemMain
```

## Folder structure

- `src` — source files (`src/banking` holds the account classes)
- `lib` — dependency JARs (none required for this project)
- `bin` — compiled output, generated by `javac` (git-ignored)

The `.vscode/settings.json` file configures these paths for the VS Code Java extension.
